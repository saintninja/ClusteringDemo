# Кластеризация - учебный инструментарий на C++23 с метриками качества

> 🇬🇧 English version of this document is above: [go to the top](/README.md)

**Clustering** - небольшой проект на C++23, который кластеризует табличные данные из CSV‑файлов и оценивает качество результата. В нём четыре алгоритма - **k-means (Ллойд)**, **EM для смеси гауссиан (EM-GMM)**, **DBSCAN** и **Affinity Propagation**, четыре метрики качества (**ARI, AMI, коэффициент силуэта, индекс Дэвиса-Болдина**) и Python‑скрипт для визуализации. Код написан как учебный пример: точки вариации k-means (инициализация и расстояние) - сменные стратегии, а каждый алгоритм спрятан за единым интерфейсом.

Консольная программа читает CSV, кластеризует выбранные числовые столбцы, записывает **новый** CSV‑файл со столбцом `cluster` (входной файл не меняется) и печатает отчёт с метриками.

## Возможности

- **Четыре алгоритма кластеризации** за единым интерфейсом (`Clusterer`):
  - **`kmeans`** - k-means по Ллойду. Две точки вариации - стратегии: **инициализатор** (`forgy`, `kmeans++`, `seeded`/`ssl`) и **расстояние** (`euclidean`, `manhattan`, `mahalanobis`).
  - **`gmm`** - EM‑алгоритм для смеси гауссиан с полными ковариационными матрицами. Начальные центры берутся теми же инициализаторами, что и в k-means.
  - **`dbscan`** - кластеризация по плотности с радиусом `epsilon` и порогом соседей `minPts`; выбросы получают метку `-1`. Работает с любым из трёх расстояний.
  - **`affinity`** - Affinity Propagation: число кластеров не задаётся, оно определяется параметром `preference`.
- **Полу-контролируемый k-means (SSL)**: размеченная обучающая выборка задаёт начальные центры, а её метки остаются неизменными; обучающая выборка добавляется в выходной файл. Доступно и для `gmm`.
- **Четыре метрики качества**: ARI и AMI (сравнение с эталонной разметкой), коэффициент силуэта и индекс Дэвиса-Болдина (используют только данные и найденные кластеры). Реализация сверена со scikit-learn.
- **Терпимый к формату CSV‑ввод**: UTF-8 BOM, окончания строк Windows, текстовые метки классов, пропуски (`NA`, пустые ячейки) - такие строки пропускаются и подсчитываются.
- **Необязательная предобработка**: стандартизация признаков (`--standardize`) и случайная подвыборка (`--sample`).
- **Визуализатор** на Python: диаграмма рассеяния с цветом по кластерам, шум серыми крестиками, обучающие объекты с чёрной обводкой, проекция методом главных компонент для более чем двух признаков.
- **Современный C++23**: `std::expected`, `std::span`, `std::format`; в C++‑части нет сторонних зависимостей.
- **Модульные тесты** (54 теста, CTest), в том числе сквозные прогоны на тестовых данных.

## Сборка

Сборка одинакова на всех платформах, отличается только тулчейн. Тип сборки по умолчанию - `Release`.

### Windows и Visual Studio

```bat
cmake -S . -B build
cmake --build build --config Release --parallel
build\Release\clustering_cli.exe --help
```

### Windows и MinGW (MSYS2)

```bat
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build --parallel
build\clustering_cli.exe --help
```

### Сборка под Linux

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
./build/clustering_cli --help
```

### Сборка под macOS

```bash
brew install cmake llvm       # штатный Apple Clang может оказаться слишком старым для std::expected / std::format
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_CXX_COMPILER=$(brew --prefix llvm)/bin/clang++
cmake --build build --parallel
./build/clustering_cli --help
```

### Опции CMake

| Опция                            | По умолчанию | Описание                                                       |
|----------------------------------|--------------|----------------------------------------------------------------|
| `CLUSTERING_CXX_STANDARD`        | `23`         | стандарт C++: `23` или `26` (для 26 нужен CMake ≥ 3.25 и компилятор с его поддержкой) |
| `CLUSTERING_BUILD_TESTS`         | `ON`         | собирать исполняемый файл тестов `clustering_tests`            |
| `CLUSTERING_WARNINGS_AS_ERRORS`  | `OFF`        | считать предупреждения компилятора ошибками (`-Werror` / `/WX`) |

Пример: `cmake -S . -B build -DCLUSTERING_CXX_STANDARD=26 -DCLUSTERING_WARNINGS_AS_ERRORS=ON`.
Установка: `cmake --install build --prefix <каталог>` (исполняемый файл попадёт в `<каталог>/bin`).

### Запуск тестов

```bash
ctest --test-dir build --output-on-failure      # для Visual Studio добавьте -C Release
```

Тесты читают тестовые файлы из `data/` (путь запоминается при конфигурации CMake), поэтому проект нельзя переносить после конфигурации без повторного запуска CMake.

## Основная программа (clustering_cli)

### Формат вызова

```
clustering_cli --input <файл.csv> --output <результат.csv> --columns <c1,c2,...> [опции]
clustering_cli --help
```

Опции записываются как `--имя значение` (по одному значению); единственный флаг без значения - `--standardize`. Порядок опций не важен. Запуск без аргументов или с `--help` печатает справку.

### Обязательные опции

| Опция                   | Описание                                                                        |
|-------------------------|---------------------------------------------------------------------------------|
| `--input <файл>`        | входной CSV‑файл (с строкой заголовка)                                          |
| `--output <файл>`       | выходной CSV‑файл; **должен отличаться от входных файлов** (программа не перезаписывает их) |
| `--columns <c1,c2,...>` | имена числовых столбцов‑признаков через запятую (без пробелов); обычно два и больше, допустим один |

В зависимости от алгоритма есть дополнительные обязательные опции:

| Ситуация                                 | Обязательная опция                                             |
|------------------------------------------|----------------------------------------------------------------|
| `--algorithm kmeans` или `gmm`           | `--k <кластеров>` - число кластеров / компонент смеси          |
| `--algorithm dbscan`                     | `--eps <радиус>` - радиус окрестности                          |
| `--init seeded` (псевдоним `ssl`)        | обучающая выборка: `--training <файл>` **или** `--training-fraction <доля>` |
| `--training <файл>`                      | `--training-labels <столбец>` (или `--labels`, тогда он используется для обоих файлов) |
| `--training-fraction <доля>`             | `--labels <столбец>` - эталонные классы во входном файле       |

### Необязательные опции

**Данные и общие**

| Опция                     | По умолчанию | Описание                                                                    |
|---------------------------|--------------|-----------------------------------------------------------------------------|
| `--labels <столбец>`      | -            | столбец входного файла с эталонными классами (любой текст или числа). Включает **ARI и AMI** |
| `--standardize`           | выкл.        | стандартизовать признаки (среднее 0, стандартное отклонение 1) перед кластеризацией. В выходном файле остаются исходные значения |
| `--sample <n>`            | все строки   | кластеризовать случайную подвыборку из `n` объектов (в выходной файл попадут только эти строки) |
| `--seed <n>`              | `42`         | начальное значение генератора случайных чисел (инициализация, подвыборка, разбиение на обучающую часть). Одинаковый seed даёт одинаковый результат при одном и том же компиляторе и библиотеке |

**Алгоритм и расстояния**

| Опция                     | По умолчанию | Описание                                                                    |
|---------------------------|--------------|-----------------------------------------------------------------------------|
| `--algorithm <имя>`       | `kmeans`     | `kmeans`, `gmm`, `dbscan` или `affinity`                                    |
| `--metric <имя>`          | `euclidean`  | расстояние алгоритма: `euclidean`, `manhattan`, `mahalanobis` (ковариационная матрица оценивается по всем объектам) |
| `--eval-metric <имя>`     | `euclidean`  | расстояние для коэффициента силуэта и индекса Дэвиса-Болдина. Не зависит от `--metric`, чтобы разные запуски можно было сравнивать |

**k-means и EM-GMM**

| Опция                     | По умолчанию | Описание                                                                    |
|---------------------------|--------------|-----------------------------------------------------------------------------|
| `--k <n>`                 | - (обязательна) | число кластеров (компонент)                                              |
| `--init <имя>`            | `forgy`      | инициализатор: `forgy` (случайные объекты), `kmeans++` (разнесённые объекты), `seeded` / `ssl` (средние классов обучающей выборки) |
| `--max-iter <n>`          | `300`        | предел числа итераций; если он достигнут, в отчёте будет «iteration limit reached» |

**DBSCAN**

| Опция                     | По умолчанию | Описание                                                                    |
|---------------------------|--------------|-----------------------------------------------------------------------------|
| `--eps <r>`               | - (обязательна) | радиус окрестности в единицах выбранного расстояния (зависит от масштаба данных; для признаков разного масштаба используйте `--standardize`) |
| `--min-pts <n>`           | `5`          | минимальное число объектов в окрестности **вместе с самим объектом**, чтобы он считался ядровым |

**Affinity Propagation**

| Опция                     | По умолчанию | Описание                                                                    |
|---------------------------|--------------|-----------------------------------------------------------------------------|
| `--damping <d>`           | `0.7`        | коэффициент сглаживания, `0.5 ≤ d < 1`; чем больше, тем устойчивее, но медленнее |
| `--preference <p>`        | медиана сходств | «самосходство» объектов. **Чем меньше (отрицательнее), тем меньше кластеров.** Сходство равно `-расстояние²` |
| `--max-iter <n>`          | `300`        | предел числа итераций                                                       |

Метод требует O(n²) памяти, поэтому принимается не более **6000 объектов**; для больших данных используйте `--sample`.

**Полу-контролируемый старт (только `kmeans` и `gmm`, см. [Полу-контролируемый режим (SSL)](#полу-контролируемый-режим-ssl))**

| Опция                          | По умолчанию | Описание                                                               |
|--------------------------------|--------------|------------------------------------------------------------------------|
| `--training <файл>`            | -            | CSV‑файл с размеченной обучающей выборкой (те же имена столбцов‑признаков, что и во входном файле) |
| `--training-labels <столбец>`  | значение `--labels` | столбец обучающего файла с классами                              |
| `--training-fraction <доля>`   | -            | `0 < доля < 1`: взять стратифицированную часть размеченного входного файла как обучающую выборку, остальное кластеризовать. Несовместимо с `--training` |

### Какие опции к каким алгоритмам относятся

| Опция                           | `kmeans`   | `gmm`      | `dbscan`   | `affinity` |
|---------------------------------|:----------:|:----------:|:----------:|:----------:|
| `--k`                           | обязательна | обязательна | -         | -          |
| `--init`                        | да         | да         | -          | -          |
| `--max-iter`                    | да         | да         | -          | да         |
| `--eps`, `--min-pts`            | -          | -          | да / да    | -          |
| `--damping`, `--preference`     | -          | -          | -          | да         |
| `--training*`                   | да         | да         | -          | -          |
| `--metric`                      | да         | только инициализация | да | да        |
| `--labels`, `--standardize`, `--sample`, `--seed`, `--eval-metric` | да | да | да | да |

Примечания: в `gmm` расстояние используется только для начального назначения и весов k-means++ - сами плотности используют оцениваемые ковариационные матрицы. В `dbscan` радиус измеряется расстоянием `--metric`; в `affinity` сходства равны `-d²` для `--metric`.

### Коды возврата

| Код  | Значение                                                             |
|------|----------------------------------------------------------------------|
| `0`  | успех (или `--help`)                                                 |
| `1`  | ошибка выполнения: файл не найден, неизвестный столбец, нечисловое значение, недопустимый параметр алгоритма и т. п. (сообщение печатается в stderr) |
| `2`  | неверная командная строка: неизвестная опция, нет значения или нет обязательной опции (печатается справка) |

## Формат входных данных

- Текстовый файл со **строкой заголовка**; поля разделены запятыми. Поля в кавычках с запятыми внутри не поддерживаются.
- Допустимы UTF-8 BOM и окончания строк Windows (`CRLF`); пустые строки игнорируются.
- В каждой строке должно быть столько полей, сколько в заголовке.
- Столбцы‑признаки (`--columns`) должны быть числовыми. Нечисловое значение останавливает работу с сообщением, в котором указаны столбец и номер строки данных.
- **Пропуски** - пустая ячейка, `NA`, `N/A`, `NaN`, `nan`, `null`, `NULL` - в столбце‑признаке (или в столбце меток, если он запрошен) приводят к **пропуску всей строки**. Число пропущенных строк печатается в отчёте. В выходной файл пропущенные строки не попадают.
- Метки классов (`--labels`, `--training-labels`) могут быть произвольным текстом или числами; они только сравниваются на равенство, поэтому названия классов значения не имеют.

## Выходной файл и отчёт в консоли

**Выходной файл.** Копируются все столбцы входного файла, затем добавляются столбцы:

| Столбец   | Когда        | Смысл                                                                         |
|-----------|--------------|-------------------------------------------------------------------------------|
| `cluster` | всегда       | номер кластера `0, 1, 2, …`; **`-1` означает шум** (DBSCAN) или «эталоны не найдены» (Affinity Propagation). Если имя занято, добавляется `_` |
| `origin`  | при обучающей выборке | `training` - объекты обучающей выборки, `clustered` - остальные          |

**Отчёт в консоли:**

| Строка           | Смысл                                                                         |
|------------------|-------------------------------------------------------------------------------|
| `Algorithm`      | алгоритм с фактически использованными параметрами                              |
| `Objects`        | число кластеризуемых объектов (и разбиение на обучающие / кластеризуемые, число пропущенных строк) |
| `Clusters found` | число кластеров и число объектов‑шума                                          |
| `Iterations`     | число итераций и `converged` / `iteration limit reached`                       |
| `Time`           | время самой кластеризации (без чтения и записи файлов)                         |
| `Quality`        | ARI, AMI, силуэт, Дэвис-Болдин (`n/a` - не определено, см. ниже)               |

## Метрики качества

| Метрика                   | Нужна эталонная разметка | Хорошее значение | Примечания |
|---------------------------|:------------------------:|------------------|------------|
| **ARI** (скорректированный индекс Рэнда) | да (`--labels`) | близко к 1 (0 - случайное разбиение, бывает отрицательным) | не зависит от нумерации кластеров |
| **AMI** (скорректированная взаимная информация) | да (`--labels`) | близко к 1 | нормировка средним арифметическим, как в scikit-learn по умолчанию |
| **Коэффициент силуэта**   | нет                      | близко к 1 (диапазон -1…1) | нужно минимум 2 кластера |
| **Индекс Дэвиса-Болдина** | нет                      | **чем меньше, тем лучше** (≥ 0) | нужно минимум 2 кластера |

- `n/a` у ARI/AMI означает, что не задан `--labels`. `n/a` у силуэта / Дэвиса-Болдина означает, что найдено менее двух кластеров.
- Шум DBSCAN (`-1`) для ARI и AMI считается ещё одним классом (как в scikit-learn) и **исключается** из расчёта силуэта и Дэвиса-Болдина.
- Силуэт считается за O(n²), поэтому на десятках тысяч объектов заметно медленнее.
- Расстояние для двух внутренних метрик задаётся `--eval-metric` (по умолчанию евклидово).

## Полу-контролируемый режим (SSL)

SSL - это k-means (и аналогично EM-GMM) с **размеченной обучающей выборкой**:

1. Начальные центры - **средние по классам обучающей выборки**. Класс с номером `i` в отсортированном порядке меток классов становится кластером `i`.
2. Во время кластеризации метки обучающих объектов **никогда не меняются**, но их координаты участвуют в пересчёте центров. Поэтому у границ кластеры могут накладываться друг на друга.
3. Обучающая выборка **объединяется** с кластеризуемыми объектами: в выходном файле сначала идут строки обучающей выборки (`origin = training`), затем остальные (`origin = clustered`).
4. Если метки кластеризуемых объектов известны (`--labels`), отчёт печатает метрики дважды: по всем объектам и только по кластеризуемым (обучающие объекты делают первую строку оптимистичной).

Обучающая выборка берётся из отдельного файла или из размеченного входного файла:

```bash
# отдельные файлы: в unlabelled.csv нет классов, в train.csv есть столбец "color"
clustering_cli --input unlabelled.csv --output result.csv --columns x,y --algorithm kmeans --k 4 --init ssl --training train.csv --training-labels color

# 2% размеченного файла служат обучающей выборкой, остальное кластеризуется
clustering_cli --input data/boxes.csv --output result.csv --columns x,y --labels color --algorithm kmeans --k 30 --init ssl --training-fraction 0.02
```

Правила: число классов обучающей выборки не должно превышать `--k` (если `--k` больше, недостающие центры берутся из неразмеченных объектов); `--init ssl` и обучающая выборка используются только вместе; DBSCAN и Affinity Propagation обучающую выборку не поддерживают.

## Архитектура и паттерны проектирования

| Паттерн / приём     | Где                                                                                         |
|---------------------|---------------------------------------------------------------------------------------------|
| **Strategy**        | `DistanceMetric` (Euclidean, Manhattan, Mahalanobis) и `CentroidInitializer` (Forgy, k-means++, Seeded) - две точки вариации k-means |
| **Внедрение зависимостей** | `KMeans` и `GaussianMixture` получают инициализатор, расстояние и зафиксированные назначения через конструктор и знают только интерфейсы |
| **Factory**         | `MakeMetric`, `MakeInitializer`, `MakeClusterer` создают объекты по настройкам командной строки |
| **Facade**          | `RunPipeline` скрывает чтение, предобработку, кластеризацию, оценку и запись за одним вызовом |
| **Объекты‑значения, `std::expected`** | `Matrix`, `TrainingLabels`, `Result<T>`: ошибки внешних слоёв (файлы, командная строка) - значения, недопустимые параметры алгоритмов - исключения |
| **Принцип открытости/закрытости** | новый алгоритм, расстояние или инициализатор - это новый класс плюс одна строка в фабрике |

Как добавить своё:

- **Новое расстояние**: наследуйтесь от `DistanceMetric` (`Distance`, `Name`), добавьте значение в `MetricKind` и строку в `ParseMetricKind` / `MakeMetric`.
- **Новый инициализатор**: наследуйтесь от `CentroidInitializer` (`Initialize`, `Name`), добавьте его в `InitializerKind` и в `MakeInitializer`.
- **Новый алгоритм**: наследуйтесь от `Clusterer` (`Fit`, `Describe`), добавьте его в `AlgorithmKind`, `ParseAlgorithmKind` и `MakeClusterer`.

## Шпаргалка по API

| Тип                           | Назначение                                                                 |
|-------------------------------|----------------------------------------------------------------------------|
| `Matrix`, `Point`             | матрица объектов по строкам; строка - `std::span<const double>`            |
| `Clusterer`                   | `ClusteringResult Fit(const Matrix&)`, `std::string Describe()`            |
| `ClusteringResult`            | `labels` (`-1` - шум), `centers`, `iterations`, `converged`, `ClusterCount()`, `NoiseCount()` |
| `DistanceMetric`              | `double Distance(Point, Point)`; `MetricPtr` = `std::shared_ptr<const DistanceMetric>` |

| `FixedAssignments`            | `std::vector<std::optional<int>>` - объекты, чей кластер менять нельзя     |
| `QualityEvaluator`            | `QualityReport Evaluate(data, predicted, truth = {})`                      |
| `RunConfiguration`            | все настройки запуска; `ParseCommandLine` заполняет, `RunPipeline` выполняет |

## Возможные проблемы и их решение

- **ARI / AMI равны `n/a`.** Программа не знает эталонной разметки: добавьте `--labels <столбец>`. Силуэту и Дэвису-Болдину она не нужна.
- **`Error: column 'z' not found in the input file`.** Имя в `--columns` должно в точности совпадать с заголовком (с учётом регистра, без пробелов вокруг запятых). В PowerShell берите значение в кавычки, если в нём есть специальные символы.
- **`non-numeric value ... in data row N`.** В столбце‑признаке есть текст. Выберите числовые столбцы или почистите данные; пустые ячейки и `NA` допустимы (такие строки пропускаются).
- **`output file must differ from the input files`.** Укажите другой `--output`.
- **k-means с `forgy` даёт плохой результат.** Случайные начальные центры могут попасть в одну группу. Используйте `--init kmeans++`, попробуйте несколько значений `--seed` или режим SSL.
- **DBSCAN: всё в одном кластере или всё шум.** `--eps` зависит от масштаба данных: уменьшайте, если получился один большой кластер, и увеличивайте, если всё шум. Признаки разного масштаба стандартизуйте (`--standardize`).
- **Affinity Propagation: слишком много кластеров / `iteration limit reached`.** Уменьшите `--preference` (например, `-4000`, `-60000`), увеличьте `--damping` (0.8–0.9) и `--max-iter`.
- **`affinity propagation needs O(n^2) memory ...`.** Объектов больше 6000: добавьте `--sample 2000`.
- **`covariance matrix of the data is not positive definite`** (`--metric mahalanobis`). Два столбца линейно зависимы; уберите один из них.
- **`training set has more classes than requested clusters`.** Увеличьте `--k` или оставьте в обучающем файле только нужные классы.
- **`--init seeded needs a training set` / `a training set is used only together with --init seeded`.** `--init ssl` и `--training` / `--training-fraction` всегда используются вместе.
- **Ошибки компилятора про `std::expected` или `std::format`.** Компилятор или его стандартная библиотека слишком старые; нужны GCC 13+ или Clang 16+ (с libc++ 17+ или libstdc++ 13+). В Windows установите MSYS2 `mingw-w64-x86_64-gcc`.
- **Визуализатор: `ModuleNotFoundError`.** `pip install numpy pandas matplotlib`.
- **Визуализатор: окно не открывается (сервер, SSH, CI).** Используйте `--save picture.png`.
